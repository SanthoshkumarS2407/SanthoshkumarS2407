## 🌟 Key Highlights & Features

### 🌌 1. Mathematical Constellation Particle System
- Custom **HTML5 Canvas 2D** particle network simulation.
- Real-time particle connection lines calculated with Euclidean distance formulas (`dist = sqrt(dx² + dy²)`).
- Dynamic cursor gravity and repulsion physics responding to mouse velocity and touch events.

### 💻 2. In-Browser Developer CLI Sandbox
- Realistic bash-style command emulator with rich ANSI-style colored output.
- Command history navigation with `ArrowUp` and `ArrowDown`.
- Interactive autocomplete and quick-trigger action pills.
- Support for system utility commands (`help`, `whoami`, `skills`, `projects`, `education`, `certs`, `cat resume`, `sudo hire`, `clear`, `contact`, `echo`, `theme`).

### 🎨 3. Warm Obsidian Glassmorphism System
- Custom CSS Custom Properties (`--bg-primary`, `--accent-primary`, `--glass-bg`, etc.).
- Dual-theme support (Warm Obsidian Dark & Clean Linen Light mode) with local storage persistence.
- Smooth scrollspy navigation with active section indicator and top scroll progress bar.
- Custom mouse cursor trailing glow with micro-interactions.

### 🏗️ 4. Interactive Architecture & System Flow Modals
- Modal popups providing system engineering breakdowns for:
  - **Smart Helmet IoT Safety System:** IR interlock logic, MQ-3 alcohol telemetry, and GSM/GPS alert dispatch.
  - **Digital Village Learning Platform:** Low-bandwidth media caching, JWT authorization, and MongoDB schema design.
  - **Public CRM Application:** Lead conversion pipelines, RESTful routing, and analytics aggregation.

## 💻 Interactive Terminal Commands

The built-in CLI terminal supports the following commands:

| Command | Action |
|---|---|
| `help` | Lists all supported terminal commands |
| `whoami` | Displays professional summary, target roles, and university background |
| `skills` | Prints categorized technical competencies and tools |
| `projects` | Lists featured projects with descriptions and tech stacks |
| `education` | Details academic credentials, B.Tech IT degree, and scores |
| `certs` | Displays verified certifications (Infosys, Cisco, Salesforce) |
| `cat resume` | Displays resume summary and triggers one-click PDF download |
| `sudo hire` | Unlocks direct hiring contact information and booking details |
| `contact` | Prints email, phone, LinkedIn, and GitHub links |
| `theme [dark/light]` | Toggles the site theme directly from the terminal |
| `clear` | Clears the terminal screen buffer |

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/SanthoshkumarS2407/Portfolio.git
cd Portfolio
```

### 2. Run locally in your browser

You can open `index.html` directly in any web browser, or launch a lightweight local development server:

#### Using Node.js:
```bash
npx serve .
```

#### Using Python 3:
```bash
python -m http.server 3000
```

#### Using VS Code:
Install the **Live Server** extension and click `Go Live` at the bottom toolbar.
