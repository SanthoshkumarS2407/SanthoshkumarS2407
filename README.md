### 🛡️ [Smart Helmet IoT Safety System](https://github.com/SanthoshkumarS2407)
**Intelligent Microcontroller Safety Telematics & Accident Prevention Engine**

[![Hardware IoT](https://img.shields.io/badge/Category-Hardware_%26_IoT_Safety-00b894?style=for-the-badge&logo=arduino&logoColor=white)](https://github.com/SanthoshkumarS2407)
[![Embedded C++](https://img.shields.io/badge/Stack-Arduino_•_GSM%2FGPS_•_MQ--3-38BDF8?style=for-the-badge&logo=microchip&logoColor=white)](https://github.com/SanthoshkumarS2407)

An automated IoT-driven rider safety and distress dispatch system designed to enforce compliance and save lives during road emergencies.

* 🔒 **Smart Ignition Interlock:** Implemented IR optical sensors verifying helmet presence before transmitting an RF ignition enable signal to the vehicle engine.
* 🧪 **Real-Time Impairment Screening:** Interfaced MQ-3 electrochemical alcohol sensor to detect intoxication levels and automatically lock ignition triggers.
* 🛰️ **Automated Telematics & Crash Dispatch:** Integrated vibration threshold triggers with GSM/GPS telematics module to immediately dispatch automated SMS notifications containing exact coordinates to emergency contacts upon crash detection.

**Tech Stack:** Arduino Uno · MQ-3 Gas Sensor · IR Sensors · GSM Module · GPS Module · Embedded C++  
🔗 [Source Code & Documentation](https://github.com/SanthoshkumarS2407)
