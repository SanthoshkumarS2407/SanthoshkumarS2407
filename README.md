## 🚀 Live Demo & Features

- **Interactive Canvas Network**: Dynamic constellation background reacting to mouse interaction.
- **Developer CLI Terminal**: Interactive in-browser terminal emulator supporting `whoami`, `skills`, `projects`, `education`, `certs`, `cat resume`, `sudo hire`, `clear`, and command history navigation.
- **Humanised & Warm Design System**: Warm obsidian dark theme with sunset amber glows and an ivory/linen light mode.
- **Interactive Project Showcase**: Category filters and popup Architecture Modals detailing hardware & full-stack flows.
- **Responsive Architecture**: Mobile-friendly navigation with responsive breakpoints.
- **One-Click Contact & Resume Access**: Fast clipboard copying and direct resume PDF download.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (CSS Custom Properties, Glassmorphism, CSS Grid & Flexbox)
- **Interactivity**: Vanilla JavaScript (ES6+)
- **Typography**: Space Grotesk, Plus Jakarta Sans, JetBrains Mono
- **Icons**: Font Awesome 6

## 📦 Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SanthoshkumarS2407/Portfolio.git
   cd Portfolio
   ```

2. **Run locally:**
   - Simply open `index.html` in your favorite browser, or
   - Using Node.js:
     ```bash
     npx serve
     ```
   - Using Python:
     ```bash
     python -m http.server 3000
     ```
